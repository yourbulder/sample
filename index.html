PRIVACY

Camera and local processing

Camera permission is requested only after you choose Enable camera. Hand landmarks are processed in this browser tab; this project does not contain video recording or an upload of camera frames. MediaPipe's SDK can send performance and usage metrics to Google even though input images are processed on-device. MediaPipe privacy notice.

QUICK TOOLS

Personal utilities

These tools run locally in this browser. Notes are saved on this device only.

VOICE CONTROL

Talk to JARVIS

Use one-time, user-triggered browser speech recognition for commands such as “Jarvis, open solar system”, “Jarvis, open notes”, “Jarvis, start stopwatch” or “Jarvis, take screenshot”. The microphone is off by default and stops after one command or seven seconds. Commands must start with “Jarvis”; low-confidence results are ignored. Supported browsers also get echo cancellation and noise suppression on the supplied audio track. Speech recognition availability and noise filtering vary by browser.

Voice command listener
Microphone is off until you start voice control.
ABOUT THIS BUILD

Single-file edition

All interface HTML, CSS and application logic are inside this one file. MediaPipe's runtime, WebAssembly files and hand model are loaded from Google's public hosting when you enable the camera, so an internet connection is required for hand tracking.

Notes, quiz scores and preferences are stored locally in this browser. Voice recognition may use the browser vendor's speech service. JARVIS is an independent browser project and is not an official Marvel or Iron Man product.
