JARVIS LEARNING ACADEMY

Learn by exploring.

Choose a hands-on lesson. Each lesson opens in the interactive stage so you can select, move and inspect its objects.

☼

Solar System Explorer

Explore the Sun and planets, compare their order and inspect simple planet facts.

◇

3D Geometry Lab

Manipulate geometric solids and learn faces, edges, vertices and symmetry.

½

Fractions Workshop

Compare halves and quarters using movable fraction bars and equivalent values.

⚛

Atom Explorer

See a simplified atom model with a nucleus and electron shells.

✎

Air Whiteboard

Write and sketch in the air. Pinch and move to draw, then use Clear to start again.

↗

Physics Playground

Move simple objects and explore gravity, bouncing and motion in a visual sandbox.

These are introductory visual demonstrations, not validated scientific instruments or full 3D simulations. Lesson facts are simplified for exploration.

PRIVACY

Camera and local processing

Camera permission is requested only after you choose Enable camera. Hand landmarks are processed in this browser tab. This project does not contain video recording, server upload or account sign-in.

ABOUT THIS BUILD

Single-file edition

All interface HTML, CSS and application logic are inside this one file. MediaPipe's runtime, WebAssembly files and hand model are loaded from Google's public hosting when you enable the camera, so an internet connection is required for hand tracking.

JARVIS is an independent browser project and is not an official Marvel or Iron Man product.
